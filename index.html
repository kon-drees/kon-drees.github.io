Projects

Token Trail Replay
master’s thesis, in progress

Token-based replay checks how well a recorded process run fits a process model. The thesis works on a single measure built from token trails that covers simple traces, partial orders and labelled Petri nets, and falls back to the known replay variants in the simpler cases. Written as a constrained optimisation problem.

Python, LP/ILP, Petri nets

Fake News Detector
university project, team of four

A FastAPI service where DistilBERT classifies a news article, SHAP shows which words pushed the decision, and an optional LLM agent checks individual claims with a web search. Shaped much of the product, co-built the agent, wrote its search tool and decided to run it only on request, since it is slower and costs money. The scores on our own test set were close to perfect; on current news the model was less reliable. Finding out why taught us more than the scores did.

Python, PyTorch, Hugging Face Transformers, SHAP, Pydantic AI, MongoDB, Docker
